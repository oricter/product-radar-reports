1. 发生了什么

北京时间约 2026-10-23，阿里巴巴集团旗下高德与阿里 ATH 发布全身基座模型 λ0（论文 arXiv:2610.18950）。项目页 lambdahumanoid.github.io、代码仓 LambdaHumanoid/openlambda（约 30★）、样例数据 HumanVerse-500-sample 同日可访问。量子位、腾讯新闻（猎云网）、网易财经等同日有中文通稿；周五日报未收录，故本轮补报。

2. 产品介绍

  • 输入输出：部署时吃机器人相机图 + 语言指令 + 本体感知，输出全身运动 token 与手部指令；身体侧由 SONIC 执行。采集阶段用人（GoPro 第一视角 + PICO 身体追踪 + 手部重建），部署不再需要人体追踪。
  • 数据：HumanVerse-500 = 约 500 小时开放世界无本体全身数据；另有约 600 条任务对齐人类示范留给 Stage III。
  • 三阶段训练：I 第一视角手部预训练 → II 机器人对齐的全身人类 mid-training → III 机器人后训练。
  • 官方数字（论文/项目页，非第三方复现）：真机成功率 62.5%（25/40）、任务进度 80.4%；SIMPLE 仿真 90.0%；对照表里 π₀.₅ 40%、StarVLA 27.5%、GR00T N1.6 7.5%。采集效率自称约 3.4×（人采 ~29s vs 机器人采 ~100s）。

怎么看（3 分钟） 打开 项目页 滚到 Laboratory / Break room / Visitor center 看真机短片；再看 Zero-Shot Transfer on Unitree G1 与真机对照表。若关心数据管线，读 arXiv 里 Observation / Action alignment 两节，并对一下 GitHub 硬件配置说明。
对我们意味着什么 λ0 不是视频世界模型，但是「开放世界人类 egocentric 数据 → 可控全身策略」的完整故事：采集效率、人机对齐、文字指令部署，都和阿汤公司做输出/数据生产直接可对标。注意：它比拼的是人形真机任务，不是 WBench 式交互视频；完整权重未放，短期不能当可下载对手跑榜。

2. 产品介绍

  • 形态：真正的 speech-to-speech；全双工（边听边说、可插话、会 backchannel）。
  • 训练叙事：官方称「No text, no pretrained models」，在单台 NVIDIA GB200 NVL72 上训成；知识也来自对话声音而非外挂 LLM（与 GPT-Live 等「语音壳 + 文本脑」路线对照）。
  • 运行：宣称本地可跑在 MacBook Pro M4 Max 或更好。
  • 访问：研究预览，安全研究员申请；公众不能玩。

结论：这是一篇「多智能体能不能靠自组织扩到上千」的研究级开源，不是面向普通用户的新产品。Agensh 去掉 lead agent，让 worker 通过 Gitea + Mattermost + 共享看板自己认领、验证、合并；在 ProgramBench 最难 5 题上，1→128 agents 平均通过率 19.31%→28.78%，Pandoc 1→1024 为 33.89%→55.06%。适合做 Agent 基建/编排的人读论文 + 跑 Docker；中文一线媒体几乎还没跟。

1. 发生了什么

约北京时间 2026-10-23/24，Microsoft Research 放出项目页 agens-harness.github.io/project、论文 arXiv:2609.26781、代码 microsoft/Agensh（MIT，抓取时约 302★ / 37 forks）。MarkTechPost 10-24 长文解读；青云TOP 10-25 有中文编译向介绍。

2. 产品介绍

  • 循环（写在 prompt 里，不是硬编码角色）：Gather → Claim → Act → Verify → Merge。
  • 基础设施：Gitea 共享仓库、Mattermost 频道/私信、共享上下文看板（OBSERVED / FACT / FAIL / CLAIM / PATCH_SUMMARY）。
  • 底座：实验用 GitHub Copilot CLI；宣称可薄适配到 Claude Code 等。
  • 怎么跑：单机 Docker Compose 默认 8 workers；1024 规模实验用 16 节点 × 64。需要 Linux、Compose v2、ProgramBench、模型 API token。
怎么看 先看项目页 Figure 1 的 scaling 动画与五任务表；再打开 GitHub README / reproduction guide。若只想判断「值不值得跟」，看涌现行为描述：8 人协商接口 → 32 人互审 → 128 人标准化集成 → 1024 人出现 integrator 角色。

3. 导致什么影响（竞品对比）

对比谁差在哪
Claude Code agent teams / Codex sub-agents / Copilot fleet / Kimi Agent SwarmMarkTechPost 对照表：前者多有中心编排或 lead session；Agensh 明确去掉 orchestrator，靠共享 Git + 消息自组织，并公开测到 1024。
普通「多 Agent 框架」Agensh 的价值在规模实验数据（同模型、同预算、离线 6h），不是又一个 SDK。平均分提升有限（+9.5pt），但单任务与速度收益更明显。
对我们意味着什么 若内部在跑多 Codex/Claude 并行改仓，Agensh 提供的是「去中心化认领 + 共享看板」参考实现；注意 token 成本论文未披露，1024 规模是研究配置不是默认产品形态。

2. 产品介绍

  • 底座：744B 参数 MoE GLM-5.2；总参数卡上写 753B。
  • 定位：科研与工程 agent——工具调用、多步、失败恢复；强调可执行可验证结果。仅文本输入（非多模态）。
  • 部署：SGLang ≥0.5.13.post1、vLLM ≥0.23.0；国内外 API；给出 Codex / Claude Code / Kimi Code 接入注意事项（必须声明 text-only）。
  • 官方演示看到了什么：蛋白结构预测微调实验曲线与 3D 结构对比；火箭/摩托车/灵巧手 CAD；《三国演义》官渡之战动画地图；约 440 粒子纯 PPT Morph 短片；多表对账数据分析。以上均为官方录屏/交互 demo，不是第三方复现。
怎么看 打开 atria-asi.ai 滚官方演示；需要权重则去 HF/ModelScope 拉 Atria-Dawn（别下成 Preview）。看跑分时盯脚注：多数项用 Claude Code / OpenHands 等 harness，条件不统一，不能直接当「绝对排名」。
