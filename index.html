1. 发生了什么

北京时间约 2026-10-27 凌晨（美东 10-26），OpenAI 在官网发布 Introducing GPT-6.1 Terra；API 模型名 gpt-6.1-terra；System Card 见 Deployment Safety Hub。同一天 AWS 宣布 Bedrock 正式可用。此前 10-25 微软 / GitHub 配置泄漏已在 X 刷屏；投资界转载的新智元稿是泄露曝光，不是正式发布通稿——见下文媒体区标注。

2. 产品介绍

  • 能干啥：读屏幕 → 跨应用点击/打字；官方举例：读发票录入会计软件、填表、读建筑图纸转 3D、逐镜头做影片修复时间码日志、草稿提案、剪辑。
  • 上下文：AWS / 开发者文档口径约 100 万输入 token；支持文本 + 图像。
  • 官方自测亮点（非第三方）：Agents’ Last Exam 中等推理比 5.6 Terra +15 个百分点、成本约 1/3，并称与 GPT-6 Astra 接近、价约 Astra 的 1/10；任务完成速度称比 Astra / Sol 快 3 倍以上；最高推理下「每任务成本约 Claude Opus 5.5 的 1/9」。MMMU-Pro 各档超过 5.6 Terra；OSWorld 2.1 中等推理超过 5.6 最佳分。Terminal-Bench 4.0 最高推理 50.3%（5.6 Terra 公布 21.5%）。内部幻觉诱导集：低推理错误率 53.6%→16.7%，最高推理降至 4.3%。
  • 安全：Preparedness Framework 下网络安全达 Critical 门槛；对齐改进沿用 GPT-6 系列，称更愿说明局限、抗提示注入更强。
  • 谁能用、多少钱：Plus / Pro / Enterprise / Edu → ChatGPT Work + Codex；开发者 API gpt-6.1-terra：$1 / $5（入/出）每百万 token。Bedrock 也可调。

开源 AgentBOSS直聘南北阁开源 Nanbeige4.3-33B：先造 33B 教师，再蒸馏 3B

结论：国内开源里值得记一笔的 agentic 中杯。BOSS直聘（Kanzhun）旗下 Nanbeige（南北阁） 放出 Nanbeige4.3-33B（及 Base）：33B dense、BF16、Apache 2.0、最长 512K。官方策略写得很直——先训高容量教师，再蒸馏即将到来的 Nanbeige4.3-3B。模型卡自称约 30B 开源档 agentic SOTA（对 Qwen3.8-27B / Muse-Glimmer-30B / Gemma4-31B），但全部是厂方同 harness 自测；HF 抓取时约 601 likes / 两千余下载，第三方独立复现榜尚未成气候。

1. 发生了什么

HF 仓库创建时间戳约 2026-10-24（UTC）；官方 X @nanbeige 在北京时间约 10-25 宣布开源。智源社区 AREX 长文整理 发于 10-26。权重：Nanbeige4.3-33B + Base。

2. 产品介绍

  • 规格：33.1B 参数、BF16、Apache 2.0、上下文至 524,288（512K）；聊天模板可开关 thinking / preserve_thinking，工具调用推荐 XML 格式。
  • 定位：4.3 系列旗舰教师；马上要服务蒸馏管线（首个目标 3B）。
  • 厂方自报（务必标注）：Terminal-Bench 2.1 80.9（Qwen3.8-27B 73.0）；Terminal-Bench 4.0 23.8（Qwen 6.3 / Gemma4 0.0）；DeepSWE 65.5（Qwen 42.5）。SWE-Bench Pro 与 GDPval 上反而略输 Qwen3.8-27B。JobBench 总分 44.8 vs Qwen 34.5，但医疗管理 / 行政 / 客服等岗仍落后。
  • 怎么跑：Transformers / SGLang / vLLM；官方示例按 4 卡张量并行，reasoning-parser 与 tool-call-parser 走 qwen3 系。
官方暂无完整公开 demo 视频。上表分数均来自模型卡「同一套超参 + harness」自测；Terminal-Bench 4.0 / DeepSWE 用 mini-swe-agent v2.4.6，SWE-Atlas-QnA 用 GPT-6 Sol 当裁判——读分时要连评测设定一起看。
怎么看 打开 HF 模型卡 直接读 Benchmark 表与脚注 1–12；中文可读智源 AREX 整理。若只关心「能不能当小 Agent 教师」，盯 Terminal-Bench 4.0 / DeepSWE / Automation Bench，并等独立 harness 复现。
对我们意味着什么 与世界模型无直接竞品关系；价值在「开源 30B 档 agentic 教师 → 蒸馏 3B」路线是否跑通。若内部要便宜的中文/工具调用底座做数据生产辅助，可列入候选，但先别把厂方 Terminal-Bench 4.0 的 23.8 当成可复现排行榜分。

3. 导致什么影响（竞品对比）

对比谁差在哪（有证据）
Qwen3.8-27B模型卡主对照。Nanbeige 在多数 agentic coding / cowork 自测领先；SWE-Bench Pro、GDPval 略落后。独立横评未出。
Muse-Glimmer-30B / Gemma4-31B同表自测中 Nanbeige 多数项明显更高；Gemma4 在 GPQA Diamond 上更高（91.3 vs 89.5）。
自家历史 Nanbeige4.x-3B以往公开线集中在 3B；这次先放 33B 教师，是发布次序的战略变化。
Atria Dawn 等超大 MoE（已报）体量与许可完全不同：Dawn 是 744B MoE 研究向；Nanbeige 是可单机集群部署的 33B dense 商用友好权重。

长上下文新实验室Mirendil 发布 Fern 0.1：最高 1000 万 token 上下文，early access

结论：新美国实验室 Mirendil（团队背景含前 Anthropic / Google 等人）放出首个模型 Fern 0.1：从零预训练的 coding / AI R&D 向模型，宣称架构与 serving 支持最高 10M tokens（约 23MB 代码、约半百万行）。现在只有 early access 申请，无公开权重、无标价。官网 RULER 长文说明写着：多数长度平均 100 例，10M 档只平均 20 例——这是小样本探路，不是可对标的独立大榜。Agentic 早期分（如 Terminal-Bench 4.0 官网图约 6.1%）也显示 0.1 仍是短轮后训练预览。

1. 发生了什么

官网新闻页标注 October 26, 2026, 8:00 am PT（约北京 10-26 23:00）：Introducing Fern。联合创始人 Behnam Neyshabur 等在 X 同步官宣。路线图还摆了更大的 Mirendil-Base-Large（0.5–2T）与 Base-XL（2–10T）预训练进度条。

2. 产品介绍

  • Fern 本体：基于 Mirendil-Base，尺寸口径约 0.1–0.5T；0.1 = 短轮后训练预览，官方称会频繁发新版本。
  • 卖点场景：审预训练 shard、从超长训练日志排错、通读完整 agent / 训练 trace、在更大 repo 上做 agentic coding——服务「造 AI 的人」而非通用聊天。
  • 长上下文证据（官方）：bits-per-byte 曲线画到约 10.2M tokens；RULER 多任务热力图到 10M，但 10M 单元格 n=20。
  • 早期 agentic 分（官网图，厂方整理）：Terminal-Bench 4.0 Fern ≈6.1，对照同图 Opus 5.5 ≈66.4、GPT-6 Astra ≈57.9——说明 0.1 还不是 coding 榜选手，叙事重心在「上下文宽度 + base 质量」。
  • 访问：early access 表单；成稿时无权重、无公开 API 价。
官方暂无完整可下载的产品 demo 视频（发布以图文 + 交互图表为主）。务必把「10M 上下文」和「10M 评测只有 20 条」两句话一起读，避免被营销数字带跑。
怎么看 打开 新闻页，先看 Context is intelligence 与 RULER 注脚，再看 Early post-training 的 agentic 表。若关心 base 质量，看 bits/byte 对比 DeepSeek-V4-Pro-Base / Nemotron 等——那是官方自测曲线。
对我们意味着什么 与交互世界模型无直接对打，但「超长上下文吃完整 agent trace / 训练日志」会改变 AI R&D 工作流预期。若公司日志与轨迹很长，可把 Fern 列入 early access 观察名单；当前 0.1 不适合当 coding 主力对标。

3. 导致什么影响（竞品对比）

对比谁差在哪
Kimi / GLM 等长上下文开源或 APIFern 强调从零预训练的 code/AI-R&D base + 宣称 10M；多数现网产品窗口远低于此。开源可跑性 Fern 目前落后（无权重）。
GPT-6 / Claude / Gemini 长上下文档通用助手生态成熟、工具链全；Fern 0.1 是垂直 early access，用宽度换通用完整度。
同页对照的 Beam / Inkling 等官网 bits/byte 与 agentic 表把它们画在一起；属厂方拼盘，不是第三方统一榜。
