1. 发生了什么

2. 产品介绍（只有舞台演示）

我把 X 上流传的 4 分 20 秒现场片段每 10 秒截一帧看完了（画面是现场大屏，带观众席，不是官方高清版）。按出场顺序：

  • 造一个世界（0:30–1:00）：大屏左上角标着「世界生成区」，一个微缩小人在巨大的马克杯旁、木地板上跑，地上有洒出来的液体，下方有文字输入框。Tim 说「我想在杯子边多一个勺子」，勺子出现，角色还能沿着它爬（电脑王阿达描述；0:40 的截图里能看到输入框里写着「……一个勺子」）。
  • 把老电影变成世界（1:10–1:50）：放周星驰《喜剧之王》片段（据报道已取得授权），左边画一条「运镜轨迹」，右边是「原视频」，生成原片里没有的机位和特写（1:40 的画面标着「侧脸到背面环绕」「背面由远拉近」）。
  • 任意门（2:00–2:30）：在房间里开门，门后是飞船走廊和太空。
  • 机器人训练（2:40–2:50）：大屏出现场景的点云和一条蓝色相机轨迹（相当于先把场景重建成 3D），旁边是机械臂在桌面上收杯子和盘子。
  • 自动驾驶和其他（3:00–3:30）：车内视角，前方有水泥罐车；还闪过火场、海底、雪地等场景，Tim 说可用于灾害救援、物理实验预演，戴 Pico 头显让医生模拟手术。片尾是纸飞机飞行的画面。

3. 导致什么影响

对行业：国内三家大厂的世界模型都亮牌了，而且路线分得很清楚——阿里做「能玩的产品 + 云 API」，腾讯做「开源 + 可导出的 3D 资产」，字节这次展示的是「内容平台入口」：抖音的创作者、直播和短剧，加上 Pico 头显。字节演示里的「给老电影换机位」「任意门拼接空间」两种用法，在别家的公开演示里不常见。

对数据生产：如果 36 氪说的「世界模型数据预算是同行 3–4 倍」属实（经 The Next Web 转述），视频/3D 训练数据的采购竞争会更激烈。

和我们的关系：「我们能做到吗」5 项清单
  • 一句话生成场景，然后用键盘鼠标在里面走：我们是 WASD + IJKL + 文字，控制方式和演示一致。
  • 边走边用文字加一个物体（「杯子边加个勺子」），物体能被角色交互：我们的文字指令能不能做到「局部加物体、其他不变」？
  • 给一段已有视频，按新的相机轨迹重新生成：我们不支持逐帧位姿输入，但能不能把轨迹拆成按键序列来近似？
  • 两个场景用一扇门无缝连起来：考的是跨场景一致性。
  • 给机器人/自动驾驶当训练场：演示里出现了点云和相机轨迹，说明他们至少在讲「先重建 3D 再生成」的故事。

1. 发生了什么

美东 10 月 12 日 13:02（北京时间 10/13 01:02），Meta 超级智能实验室（MSL）发布 Muse Wonder 系列，两个型号：

  • Muse Wonder：Meta Model API 和 Muse Code 都能用，每百万 token 输入 4 美元 / 输出 20 美元，模型 ID muse-wonder-1.0。
  • Muse Wonder Full：不卖 API，只在编程工具 Muse Code 的订阅里用（每月 50 美元 Power 档、200 美元 Maximum 档）。
  • 共同点：100 万 token 上下文；能看文字、图片、视频、音频，只输出文字；闭源，不放权重；在俄亥俄州的 Prometheus 数据中心训练。离上一代 Muse Spark 1.3 只隔 6 周。
  • 以后会接入 Meta 的个人 AI 助手 Muse，先给订阅用户，没给时间表（The Verge）。

结论：游戏本身是一个 10–20 分钟的小品（文字选项 + 两条情绪数值），不是技术突破。真正的信号是人：72 岁、做了 40 多年游戏的传奇设计师公开说「不会画画、不会编程，只要给 AI 下指令就能一个人做出像样的游戏」，等于替「一个人 + 一段指令 + 30 分钟 = 能玩的游戏」做了大众背书；同时评论区的骂战说明，反 AI 舆论对知名创作者是真实成本。对世界模型做游戏的意义：「生成一个网页小游戏」的门槛已经低到聊天框级别，我们要拉开差距只能靠「能实时玩的动态世界」。

3. 导致什么影响

对 AI 游戏：「普通人用一句话做游戏」这件事，一周内有了两个大众级样本——10/9 Google 上线 Playground（我们已报道），10/11 堀井用 Claude 做了一个。前者是平台，后者是名人背书。

边界开始清楚：同一个周末，Activision 用 DMCA 下架了独立开发者用 AI 编程工具做的《使命召唤》浏览器移植版（XDA），原因是用了从原版游戏导出的地图、模型和动作。也就是说：AI 帮你做原创小游戏，法律上没问题、舆论上有争议；AI 帮你搬运别人的游戏，会直接被下架。

竞品对比

谁定位差在哪（有证据）
Claude Artifacts（堀井用的）对话生成单页网页应用，发链接分享零门槛、零发行渠道：没有社区、排行榜、联机。适合「做一个能玩的小东西给朋友看」。
Google Playground（10/9 已报道）提示词生成 2D/3D 游戏的平台有分享、社区发布、排行榜，部分类型支持多人；目前只对美国 18 岁以上用户开放（Google 博客）。比 Artifacts 多了「发行和社交」。
Square Enix《港口镇连续杀人事件》AI 技术预览版（2023）让玩家自由输入、AI 理解指令同一个 IP、同一个品类，当年因打磨不足和限制太多评价很差（Inven Global、Kotaku）。这次反过来：AI 用在「做游戏」而不是「玩游戏时对话」，反而做出了能玩的东西。
AI 辅助移植老游戏（如 Luckey Faraday 的《使命召唤》网页版）用 AI 编程工具把老游戏搬到浏览器用了原版资产，被 Activision DMCA 下架（XDA、TechPowerUp）；和堀井的原创小游戏不是一回事。
和我们的关系
  • 世界模型做游戏要避开的赛道：「生成一个规则清楚的网页小游戏」已经被大模型 + Artifacts 免费覆盖了；世界模型的价值只能在「画面实时生成、能自由走动的动态世界」。
  • 阿汤自己做副业游戏：如果公开发布，提前写清楚 AI 用在哪一环。堀井的例子说明，即使是传奇作者，也会在评论区被围攻。
