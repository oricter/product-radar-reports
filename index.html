2. 产品介绍

它想解决什么：长程 Agent 要在复杂代码库、完整项目构建、视觉编程（交互网页 / 3D / 设计）里连续干完，而不是只答一轮。官方把失败轨迹转成可复现训练题，并用大规模长程 RL + 多 harness 混合训练（Claude Code / Codex / Hermes 等）。

关键能力（官方博客）：

  • 原生视觉离散 token：不同分辨率图像 → 多层级离散 token，与文本统一进主干；支持离线预 tokenize。
  • 长程 Agentic RL：从 GitHub PR/issue 合成环境与 F2P/P2P 测试；异步 partial rollout；防 reward hacking。
  • 国芯训推：单卡 <80GB 场景下超节点感知并行；官方称长序列 SFT 单卡吞吐较 DDP 基线 +86%；W4A4 推理相对 W8A8 预填/解码吞吐约 +43% / +43%。

官方自报数字（博客表，* 为他方公开分）

  • AutomationBench v1.0.6：51.8（Opus-5 50.3*；2.0 仅 15.8）
  • BrowseComp：91.9（Opus-5 90.8*）
  • Terminal Bench v4.0：38.5（GPT-5.6-Sol 37.3*；Opus-5 53.9*）
  • 3DCodeBench Text→3D：55.4（Opus-5 54.3）
分数大量带 * 或自跑标注；不同 harness / thinking 开关会改结果。以博客脚注为准，不要口头改成「全面第一」。

对我们 若产品有语音指挥世界模型 / 游戏 Agent，优先抄「语义判停 + 只承认已说出口上下文」；评测不要只报 ASR-WER，要报抢话率、无关拒识、打断后衔接。工具成功率 51% 提醒：实时嘴炮和可靠执行要拆开验收。

评测 · 日常 AgentOpenAI 发布 LifeVal：用托儿、政务、预算等日常任务衡量 AI，高分不等于办完

结论：LifeVal 是研究型评测发布（2026-11-02），不是新 ChatGPT 功能上线。它把「人愿意交给助理的日常事」拉进榜单叙事，方向对；但公开页给的是选中任务高分示例，独立评论已指出——短名单 / 购物车里的 deed / 护理计划草稿 ≠ 报名成功、成交、医嘱生效。采购或对标时，要问清终点定义，别拿 80%+ 当完工率。

1. 发生了什么

OpenAI 于 2026-11-02 发布研究页 LifeVal：基于美国时间使用调查、跨国时间使用研究，再加 3,995 人抽样，找出人们最想要 AI 帮忙的日常任务（照护、健康、教育、家务行政、个人财务、购物、政务等），用来追踪过去一年模型在「办实事」上的进步。

一手：OpenAI · LifeVal · 评论：Nagesh Polu：高分不是办完

2. 产品介绍

它不是产品，是尺子。公开示例包括：搬家后筛选幼儿园（展示分 93.1%）、洪灾前组织志愿者（98.0%）、按预算找带独立居住单元的房子并把 deed 加进购物车（100%）、糖尿病家长的一周饮食与护理计划（90.4%）。官方强调过去一年在 browser / computer use / connectors 上的训练，让 ChatGPT 从聊天走向可行动助理。

怎么自己看（8 分钟） 打开 LifeVal 页 → 读 Background 里两份时间使用研究 + 3995 人调查 → 点开 2–3 个 Individual task examples 看模型回复停在哪一步 → 再读一篇独立评论（推荐 Nagesh Polu）问自己：终点是「草稿」还是「外部回执」？

视频：官方页以对话截图/文本示例为主，无单独发布演示片；本版不嵌无关口播。

3. 导致什么影响（含竞品）

  • vs GDPval / SemiAnalysis GDPx 等专业 Agent 榜：LifeVal 测个人生活责任，GDPx 测难专业任务；百分比不能横比。Nagesh 文强调三者任务群、工具环境、难度分布不同。
  • vs 学术知识榜 / 编码榜：把优化目标从「会答」扭向「帮人把事推进」——对 Agent 产品经理是叙事胜利，对实验室是新刷分场。
  • 对企业落地：独立评论给出的验收清单值得直接抄——外部回执、可重复试验、授权日志、异常处理、含人工复核的净耗时。
对我们 世界模型 / 游戏 Agent 评测也可以学：除了通关率，增加「用户授权点」「不可逆动作是否停住」「最终状态能否在环境外核验」。别只报平均 reward。

4. 用户如何评价

官方研究页发布 X 多为多语言摘要转发，单帖热度不高 独立博客聚焦「高分≠完工」
  • 正面：任务选取连到真实时间使用数据；把「个人助理」从口号变成可追踪曲线。
  • 批评：方法细节、全量任务、重试策略、他实验室结果未公开；选中示例分易被误读成总体完工率；「deed 进车」类终点偏准备态。
