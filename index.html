2. 产品介绍

它想解决什么：无人驾驶的安全 / 智能 / 规模「不可能三角」——长尾难靠实车覆盖、新区域试错贵、跨路段连续任务要规模化验证。Apollo World 把复杂交互与风险场景变成可重复、可控、可规模跑的虚拟测试，再反哺车端。

「2+3」标尺（官方）：

  • 基础门槛「2」：因果性（时间单向、由过去推未来，而非拼画面反推）；交互性（外部动作能改未来状态）。
  • 进阶「3」：物理准确性（学到的能力回真车还能不能用）；持久性（长跑不漂移）；实时性（世界变复杂也不拖垮推理时延）。

三大能力叙事：① 交通参与者全是可决策 AI 智能体（不是脚本道具）；② 实时相机 / 激光雷达等多模态观测；③ 任意起终点完整行程闭环（接单→载客→送达），而非单路口短片。

官方 / 媒体转述关键运营数字（厂商口径）

  • 萝卜快跑：全球 28 城；累计出行超 2300 万 次；自动驾驶总里程超 3.5 亿 公里，其中全无人超 2.4 亿 公里。
  • 媒体转述：Apollo World 可「日行十万公里」——约等于一辆有安全员的实车连测约三年（行业分析口径，非第三方审计）。
以上里程与产能数字均来自百度/媒体通稿，未见独立复现。标尺本身可当产品验收语言；产能口号先打「待验」标签。

对我们（世界模型公司） 直接可抄：① 用「2+3」当对外/对内验收语言；② 评测从「像不像」改成「动作注入后下一状态是否因果正确、长跑是否漂移、时延是否稳住」；③ 优先做完整任务闭环（起终点订单），而不是只刷单场景短视频。萝卜快跑的数据飞轮提醒：没有真实运营闭环，虚拟「日行十万」难自证。

2. 产品介绍

它想解决什么：今天你无法从输出 alone 确认「这是不是你付钱买的那台模型」——路由可能偷换成便宜模型，攻击者可能篡改 token 流，评测方也难绑死权重。FlashProve 用 zkSNARK：离线对权重做短指纹承诺；在线对（prompt, output）出证明——验过即说明被承诺的那组权重在该输入上产出了这些 token；证明本身不泄露权重。

官方关键数字（Llama 4 Maverick 4-bit，单 H100）：

  • 出证吞吐约 110 tokens/s（24 请求一批约 223 秒）
  • 证明大小约 18.78 MB / 1024-token 窗口请求
  • 验证：24 核 CPU 约 17 秒/证明（单线程约 21 秒）；承诺文件约 6.5 MB
  • 相对 vLLM 同批：证明侧约 70–95× 单卡 GPU 时间
限制写进官方 Limitations：整数贪婪解码版本；上下文目前到 1024；不隐藏架构只隐藏权重；快路径 C++ 验证器无形式化保证（Lean 慢验证器有）；明确「中间进度，非完成议程」，无上线 Anthropic 生产计划（TechCrunch 同述）。
怎么自己看（15 分钟） 打开 研究页 → 先读 Executive summary 四条与 Limitations → 再扫 Challenge 1–4（pacing / 篡改 / provenance / 审批）→ 有兴趣下 GitHub 看 README 与 guide/what-is-proved.md。中文深度稿窗内稀缺，以英文一手为准。

视频：官方以文+代码+Lean 可视化为主，无单独产品演示片；本版不嵌无关口播。

3. 导致什么影响（含竞品）

  • vs 早期 zkML（zkLLM / EZKL / VerInf / DeepProve / Attestable 等）：官方自比：此前同模型 VerInf 约 0.02 tok/s、证明近百 GB；FlashProve 同模型 110 tok/s、19 MB。Attestable 报密模 31B 约 53–77 tok/s 但未开源库。差异化是开源 + Lean 顶层陈述 + 前沿 MoE 规模。

对我们 短期不必接入推理路径；中期若要对外提供「评测绑死权重」或合规审计，关注证明开销能否压到 <10×、上下文能否拉到真实会话长度。世界模型若对外 API 出视频/动作，同类「输出归因」问题会再出现——先盯协议与验收语言。

2. 产品介绍

它想解决什么：真机采集贵、仿真搭场景难、算法验证周期长。Thinker-Sim 宣称覆盖：场景重建与资产生成 → 规模仿真数据合成 → 感知/导航/操作统一评测。

三大块（通稿）：

  • 场景重建与资产：自研 Thinker-GS 高保真重建 + SimReady 资产自动生成；工业工厂、商业展厅等。
  • 数据合成：自研渲染与大规模并行；官方称渲染效率 +67.3%，单节点（8 GPU）日均约 390 小时仿真数据；通信模块效率 +400% 以上。
  • 能力评测：感知/导航/操作统一体系；场景、光照、纹理、材质随机化。

体验向：标准化任务模板一键启动并推流；可视化零代码编排（称适配 90%+ 目标场景）；Ulab-Agent 支持自然语言完成场景创建、配置、编排与调度。

怎么自己看（8 分钟） 读 新浪科技短讯 对齐三块能力 → 再扫 盖世 是否有额外图 → 去优必选官网人形/平台页找是否出现 Thinker-Sim 产品入口（成稿时公开自助试用链接未见）。有渠道再要 demo 账号做「重建→合成→评测」一条龙。

视频：通稿未附可稳定外链的官方长演示；本版不嵌无关口播。

3. 导致什么影响（含竞品）

  • vs Isaac Sim / MuJoCo / ManiSkill / RoboCasa 等：Thinker-Sim 强调 Real2Sim 资产流水线 + 中文产业场景（工厂/展厅）+ 自然语言编排；生态与开源社区深度尚不清。
  • vs Mundo / 智元仿真与数据飞轮、NVIDIA Cosmos：同属「仿真产数据」赛道；优必选绑自家人形落地叙事。选型看你要开放可复现还是厂商交钥匙。
  • vs Apollo World：Apollo 偏 Robotaxi 虚拟城市与安全考官；Thinker-Sim 偏人形具身操作数据与评测——相邻但场景不同。
对我们 可关注两点产品化动作：① SimReady 资产自动生成是否真能降低搭景人天；② 「自然语言编排仿真任务」会不会变成具身数据生产的默认 UX。数字先记着，等可对比的公开基准或第三方工时数据再更新。
