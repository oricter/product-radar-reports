世界模型 · 符号/形式化清华姚期智团队发布 Algebraic World Model（AWM）：让 AI 从探索走向 Lean 证明

结论：AWM 不是又一个「生成可漫游视频」的像素世界模型，而是把陌生交互环境学成可执行、可凝炼、可在 Lean 4 里核验的代数模型。对产品与算法团队最有杀伤力的一点：它能在「预算少 1 步」的密封关卡上证明无解——同样装备 coding tools 的 Claude Opus 5.5 / GPT-6 Astra 在 12 次基线里一份正式证明都交不出。通关分数可以打平，但「知道何时不可能」是另一条能力轴。

1. 发生了什么

清华大学交叉信息研究院姚期智、袁洋团队公开论文与项目页 Algebraic World Model: From Exploration to Proofs（arXiv 2610.40503）。共同一作是浙大本科生潘冠成与清华姚班本科生谭淇心。北京时间 2026-11-01 前后中文热度抬升：智源社区 15:50 转载袁洋组稿，量子位 16:02 发解读。

官方一句话：AWM 把未知游戏/环境学成显式数学模型，并在 Lean 里证明「能赢」与「不能赢」。

2. 产品介绍

它想解决什么：Frontier agent 在 ARC-AGI-3 这类「不告诉你规则也不告诉你目标」的游戏里，已经能整理出密密麻麻的符号化规则（量子位比喻：像第谷的观测本）。但这些规则往往只记现象——一旦关卡被改成「少 1 步就不可能通关」，模型会幻觉出错误下界（例如 Astra 找到 22 步路线就以为最优，而真实最优是 19）。

三步流水线（官方）：

  • Explore & Prototype：边玩边写可执行 Python 假设，用观察到的转移不断检验、修订。
  • Structure & Simplify：整理成类型化对象与共享规则；用范畴论启发的投射/归纳极限变换做简化（Lean 检查通用性质）。
  • Formalize & Prove：编成 Lean 4，核验可达性与不可能性（不含 sorry / native_decide 捷径）。

关键数字（论文/项目页自报，可复现声明在站上）

  • 密封无解关：sc25 两关预算压到最优解少 1 步；AWM 6/6 跑出闭式、内核核验的 Lean 无解证明；Opus 5.5 + Astra 共 12 次基线 0 份同类证明。初始下界正确率 4/6→反馈后 6/6；基线侧多数未判定或下界错。
  • 公开 25 款 ARC-AGI-3：183/183 关 Lean 回放认证通关轨迹；Opus 5 + AWM 官方分 99.9（无 AWM 的 Opus 5 标准 harness 仅 40.7）；认证动作数 7,448 ≈ 人类基线 43%，论文表中在报该指标的系统里最少。
  • 泛化抽检：冻结规则后，未见过布局上 4,160/4,160 转移预测对；机制改动后 4,031/4,031 拒绝。
证明成立的范围是「在学到的模型前提下」。作者明确写：屏幕→状态的解析在 Python、Lean 外；模型可能比真游戏更严。证据要靠交互检验与「充分覆盖」迁移条件，不是「Lean 过了=世界真理」。

3. 导致什么影响（含竞品）

  • vs 只记规则的 frontier agent（GPT-6 Astra + Provider Adapter、Claude Opus 5.5）：通关分上 Astra adapter / Memento 3 也能冲到满分附近；差距在不可能任务——基线会幻觉步数、交不出核验证明。产品含义：Agent 说「做不到」时，你要的是证明还是感觉？
  • vs Memento 3 / 可执行代码世界模型（WorldCoder、Twin 等）：同属「交互里学规则再规划」家族；AWM 额外把规则压成代数结构并形式化证明。论文相关工作也点名：代码世界模型 100% 过采样检验仍可能因漏关键规则而输。
  • vs 公司常见像素/视频世界模型（Genie、Hy-Nomas、EdenLive 等）：那些优化的是画面一致性与可控生成；AWM 优化的是可检验的世界定律。两条路线互补，不要拿视频观感去打 AWM 的分。
对我们（世界模型公司） 若产品控制是 WASD+IJKL+文字，AWM 不能直接当渲染器；可借鉴的是「探索留下可执行结构 → 结构能证明」的评测叙事：除了通关率，增加「密封无解 / 下界是否紧」类题目，逼模型少幻觉。对标 Memento 3 时，别只比动作数，要比证明交付物。

  • vs 游戏工作室 Demo 策略：短期或加速「少放可执行 Demo、多放预告片」；长期压力在平台（Steam）治理，不单在某一家模型公司。
  • vs Anthropic 自身产品叙事：与「安全公司」品牌一致，但叠加训练数据版权和解的舆论，会被嘲「双标」。对 PM：这是合规/声誉功能，不是能力升级。
对我们（偶尔做游戏 / 用 coding agent） 内部工具链不要假设「一个模型永远肯写某类脚手架」。教学向「复刻经典练手」要改成「类型约束 + 自有美术」模板；真遇到误伤，保留会话日志按 Addy 说的反馈通道走。若评估竞品 agent，把「IP 策略松紧」写成采购维度。
