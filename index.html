2. 产品介绍

规格（媒体/preview 卡交叉）：Hy4 系列约 770B 总参、preview 卡写激活 49B、上下文 1M。正式版模型卡未公开，参数以报道为准。

新能力：

  • 视觉理解：细粒度图像、复杂图表、数学视觉推理；结合工具调用。
  • Computer Use：CLI + GUI；对 Blender、CAD 与跨应用长程任务做专项训练。
  • 产品落地：腾讯云 TokenHub、WorkBuddy/CodeBuddy、元宝、企微智能助理大圆、ima；API 经 OpenRouter / Hermes / OpenCode；QQ、王者、和平精英等持续接入。

官方自报数字（厂商口径）：WorkBuddy 均分 83.18、通过率 96.15%，12 场景中 9 个「国内第一」；金融盲测 Hy4 3.04 vs DeepSeek-V4.1-Flash 2.97 / Kimi K3.1 Pro 2.68 / GLM-5.3 2.68；幻觉率从 preview 12.95% → 7.2%；GameDev +19.1%、GameLogic +9.8%（相对 preview）。

定价：输入 6 元 / 输出 18 元 / 缓存 0.3 元（每百万 tokens），与 preview 同价；TokenHub 刊例五折至 2026-12-31；WorkBuddy/CodeBuddy 11-04～11-15 有免费额度。Hy4 Flash「近期」发布。

「最强开源」是腾讯自评；正式版权重未放时，开源排行榜无法计入正式版。独立第三方全量评测本版未见。以上金融/WorkBuddy/GameDev 数字均为厂商或合作方口径。

3. 导致什么影响（含竞品）

  • vs DeepSeek-V4.1-Flash / Kimi K3.1 Pro / GLM-5.3：腾讯自报在部分 Agent/金融任务压过；编程与顶尖闭源仍承认落后 GPT-6.1 Sol、Claude Opus 5.5。选型看你要「开源可自部署」还是「当下最强闭环」——正式版权重未到前，Hy4 更像云上产品模型。
  • vs Claude Computer Use / GPT computer use / 美团 LongCat-2.5：Hy4 把「能看 + 点界面」绑进腾讯办公/游戏生态（WorkBuddy、UE/Unity/Godot），差异在分发与共设计，不单是基准分。

对我们（世界模型公司） 可抄三点：① 旗舰迭代用「preview → 正式版 → Flash」节奏，先产品后权重；② Computer Use 专项训 Blender/CAD/游戏引擎——和 3D/世界模型工具链相邻；③ 对外话术诚实写「开源第一梯队但仍落后闭源」。权重放出后再做一次独立对比更新。

2. 产品介绍

  • 谁能用：全球 ChatGPT / Codex 全档位（桌面、手机、网页）；开发者走 Image API。

2. 产品介绍

  • 架构：MoE，总参约 35B，每 token 激活约 3B；基于 Qwen3.6-35B-A3B 独立微调（非官方 Qwen 发行版）。
  • 数据引擎：能力蓝图（实体/空间/时序/物理/可供性/任务/社会/证据等 8 一级、39 二级）→「能力编译」出题 → 提纯/几何构题/定向合成三条监督 → Eval-Driven Data Harness 用错题反哺下一轮数据。监督样本 312,380 条。
  • 自报成绩（avg@4）：十项均分 65.29；Where2Place 64.28（+9.30 vs 基座）；ERQA 64.38（+6.19）；SAT 89.33；ERQA 轨迹理解 68.18（+12.12）。
  • 公开案例题型：相机转动方向、拔充电器轨迹选择、跨视角挂画方位、寿司卷入锅任务进度——量子位文内有逐步对比基座与 Qwen3.6-27B。
模型卡写明：未验证用于安全关键或自主机器人控制；基准表现不保证迁移到新环境；训练-测试污染未独立证明。HF「Downloads last month」抓取时显示很低（个位数量级），社区热度仍早期。
怎么自己看（20 分钟） 打开 量子位长文 先读「四道公开基准题目」——看相机转动/轨迹/跨视角/任务进度四例 → 再打开 HF 模型卡 核对均分 65.29 与限制声明 → 有卡再按模型卡 vLLM/Transformers 示例跑 ERQA_155。看完应搞懂：强项是空间-时序-物理问答，不是端到端操控。

3. 导致什么影响（含竞品）

  • vs 通用 VLM（Qwen-VL / GPT-4o 类）：Lion-ER 明确优化具身题型（相机运动、可供性轨迹、任务进度），不是通用聊天视觉。
  • vs Apollo World / Thinker-Sim / Cosmos Sim-*：前三者偏仿真世界或车/机器人闭环；Lion-ER 是「看懂再决策」的感知-推理层，可嵌进仿真或真机栈，但不替代物理仿真器。
  • vs 盲目堆 Open-X / DROID：量子位叙事的差异点正是「能力牵引 vs 堆数据」——对数据生产团队是可执行的流程模板。
对我们（世界模型 / 数据生产） 强烈建议内部分享量子位文中的四步引擎：① 写细能力蓝图（别只写「空间好」）；② 能力编译出题规范；③ 评测失败→区分标注问题 vs 能力缺口；④ 用缺口驱动下一批评测同构新题。可把 ERQA/Where2Place 类题嵌进自家世界模型「文字指令」中间轮验收。
