世界模型 · 实时交互World Labs 发布 Frameboy：Atlas 世界模型进浏览器，最高约 15 fps 实时转相机

结论：这是李飞飞 World Labs 把 9 月的 Atlas 从「等几秒/几分钟出一条视频」推进到「边转相机边出画」的研究预览。产品形态是云端 GPU 推流到浏览器的 Frameboy demo，并嵌进闭测 Viewfinder。对我们：控制方式接近 WASD/相机漫游，比逐帧精确 6-DoF 轨迹更贴合自家接口；必开 frameboy.worldlabs.ai 亲测，别只看 GIF。注意：15 fps 是上限、要烧云端 GPU、官方承认比本地渲染贵。

1. 发生了什么

美东 2026-11-05（北京时间约 11-06 凌晨），World Labs 发博文 Frameboy: Atlas in Real-time，并开放研究预览 demo。Atlas 是两个月前发布的自回归世界模型：一帧一帧生成、像素级相机控制。Frameboy 跑的是高度优化的 Atlas 变体，把画面从云端 GPU 流式推到浏览器，官方写「最高可达 15 fps」。同一天把实时能力叠进网页应用 Viewfinder（闭测，需候补名单）：先逐帧搭场景，再切 Frameboy 覆盖层实时逛。

一手：World Labs 博客 11-05 · 可玩：frameboy.worldlabs.ai · 中文：凤凰网科技 · 外文：Unite.AI · RuntimeWire · Spatial Insider

2. 产品介绍

  • 交互：不是一次性出固定视频；用户像游戏里转相机，模型按位姿持续出新画面。可从单图长出可逛空间，也可用多视角照片做真实地标的新视角合成。
  • 相对 RTFM：去年有轻量实时 demo RTFM；Atlas 更大、数据更多——RTFM 偏已有视点插值，Atlas 可从单图/文本长出场景。
  • Viewfinder：逐帧生成含颜色+深度；再开 Frameboy 流式覆盖。闭测，需 waitlist。
  • 成本边界：官方明说必须跑在强 GPU 云上，「相对本地渲染不便宜」；15 fps 是峰值，不保证全场景稳帧。

World Labs 官方 · real-world-landmarks 看完应搞懂：多视角真实地标输入后，可在浏览器里转新视角，不只是幻想场景。

怎么自己看（15 分钟，优先亲测） ① 打开 frameboy.worldlabs.ai，选一个 curated 场景，用鼠标/触控转相机，感受延迟与一致性 → ② 回读 官方博文「Why speed matters」段，对照慢速迭代 vs 实时探索的两段动画 → ③ 若有 Viewfinder 资格，试「先搭后逛」。看完应搞懂：实时不是更高画质，而是把「生成」变成「导航」。

3. 导致什么影响（含竞品）

  • vs Google Genie 4（已报 10-28）：Genie 4 主打原生音视频 + 键盘/文本导演，仍是研究预览分发；Frameboy 更强调「像素级相机控制 + 浏览器实时推流」可玩入口。Genie 偏「导演世界」，Frameboy 偏「摄影机漫游世界」。
  • vs Odyssey / 快乐生蚝 / Zing 等可玩世界：Odyssey 系常见动作条件与固定分辨率实时；Frameboy 挂在 Atlas 新视角合成能力上，单图/多视图进、相机出，更像空间智能 demo，而非完整游戏引擎。
  • vs World Labs Marble / 离线 Atlas 视频导出：Marble 走可编辑持久 3D 资产；Frameboy 是流式帧生成。同一公司两条产品线：资产化 vs 即时漫游。
  • vs 可灵 / Runway 长视频：那些是「生成一条片」；Frameboy 是「持续响应用户相机」。评测口径完全不同——应对齐 WBench/交互世界，而不是单镜 VBench。
对我们（世界模型 / 数据生产） 三条可执行：① 把「交互帧率 + 相机一致性」写进验收，而不是只看离线视频美学；② 自家 WASD+IJKL 控制可对标 Frameboy 的实时相机回路做主观对比；③ Viewfinder「先搭场景再实时」接近数据产线里的 preview→explore。别被 15 fps 营销带跑——记云端成本与稳帧条件。

结论：这是 OpenAI 把网络安全专用模型从 High 拉到 Preparedness Framework 的 Critical 档，并强调「会找洞、更听授权范围」。ExploitGym 48.5% vs GPT-5.6 Cyber 32.1%（相对约 +51%）；自报在 Firefox 挖出 81 个新高危、Linux 上做出 948 个提权利用。无 ChatGPT 消费 demo——只对审核通过的 Daybreak Red 客户开 API/Codex。对我们：跟世界模型无直接产品对标，但「高能力 + 强对齐 + 窄分发」是 Critical 能力的标准打法；TechCrunch 提醒防御方资源跟不上攻击面。

1. 发生了什么

美东 2026-11-05，OpenAI 发布 GPT-6 Cyber：训练目标是在研究者划定的范围内发现并验证可利用漏洞。配套加长 System Card，并升级误用监测、IP allowlist、关键基础设施相关拦截。访问：先给部分 Daybreak Red，随后扩到全部 Red；同时向全部 Red 放 GPT-5.6 Cyber；Daybreak Blue（偏防御验证）继续扩 GPT-6 Astra。

一手：OpenAI 博客 · System Card · 外文：The Verge · TechCrunch · CSO Online · 中文：第一财经 · TechFlow

2. 产品介绍

  • 基准（厂商）：ExploitGym 48.5%（5.6 Cyber 32.1%，Astra 约 42.4%）；网页黑盒渗透新评测 recall 40.3% vs Astra 32.0%；RemoteExploitBench 上 Cyber 完成 95%，Astra+Blue 拒答 100%。
  • 对齐：ExploitGym Honeypot（仿 Hugging Face 事件）——无部署提示时 99.93% 不打范围外服务（5.6 Cyber 94.49%），有提示时 100%。
  • 真实影响（厂商/客户引言）：Firefox 81 新高危 + 帮助出补丁；Linux 复现 1724、利用 948；Cisco / Calif / CodeRabbit / Palo Alto / Dragos 等用例。
  • 谁能用：审核 Daybreak Red；API 默认 IP 白名单；另设 Critical Infrastructure 分组与 $10 亿 Frontline Defenders 补贴叙事。
无公开消费端 demo / playground。基准、漏洞计数、客户引言均为 OpenAI 或具名客户口径；TechCrunch 指出 Linux 漏洞狩猎花费约 $120 万，相对其他研究投入并不夸张，引发「资源是否够」争论。
怎么自己看（10 分钟） 读 官方博文 里 ExploitGym / Honeypot / Firefox·Linux 三段 → 扫 System Card 目录 → 再读 The Verge 与 TechCrunch 的「越界率」和「防御资源」两面。看完应搞懂：能力↑ + 对齐↑ + 分发极窄；不是人人能调的 API。

3. 导致什么影响（含竞品）

  • vs GPT-6 Astra / Daybreak Blue：Astra 是通用前沿；在多数网络攻防任务上 Cyber 更强，且 Blue 对进攻任务大量拒答。选型看你要「通用工程」还是「授权进攻研究」。
  • vs GPT-5.6 Cyber：分数与对齐双升，安全等级 High→Critical；旧模型反而向更广 Red 客户开放做过渡。
  • vs 开源「去对齐」黑客模型叙事：OpenAI 用身份核验 + IP 白名单 + PSP 监测对打；TechCrunch 采访对象仍担心坏演员用开源无护栏模型。
  • vs 传统扫描器 / 人工红队：客户引言强调长程利用链与复杂逻辑洞；不替代人工确认与补丁工程。
对我们 世界模型训练/仿真基础设施本身是高价值攻击面——关注 OpenAI 用同类模型加固自有训练基础设施的公开叙述。产品侧无直接对标需求；安全合规若接外部模型，记「Critical 能力必须配窄分发与审计」。

结论：这是 Google 把 Omni Flash 视频模型推到 正式 GA 的版本跃迁：时长 10s→15s、参考一致性增强、支持多轮对话改同一条片，720p 降到约 $0.07/秒（官方称相对 1.1 降约 30%）。入口：Gemini API、Google Cloud、Vids、Flow，以及 AI Ultra 侧 Gemini App 滚动放量。对我们：这是「短广告/商品视频产线」工具，不是交互世界模型；可当廉价分镜/营销层，别跟 Frameboy 的实时相机回路混为一谈。

1. 发生了什么

美东 2026-11-05，Google DeepMind 产品博客与 Google Cloud 博客同步宣布 Gemini Omni 1.2 Flash 在 Gemini API 与 Gemini for business / Cloud 上 GA。Workspace 更新写明 Vids 支持 15 秒生成与画质改进。输出带 SynthID；Provisioned Throughput 对企业可用；音频参考仍 allowlist。

一手：Google 开发者博客 · Google Cloud 博客 · DeepMind 模型卡 · Workspace / Vids 更新 · 中文：界面新闻快讯 · 新浪财经 · 外文综述：Unite.AI

2. 产品介绍

  • 时长：原生生成/编辑最长 15 秒（1.1 为 10 秒）；可按 1 秒步进选 3–15 秒。
  • 一致性：人物/商品/包装字体/品牌色跨镜头更稳；支持图像、≤3 秒动作片段、音频线索作参考。
  • 多轮编辑：同一条片上改背景、天气、产品、画幅，而不必整段重生成——官方示范从帐篷→森林→马厩等连续换景。
  • 成本工作流：360p/720p 快草稿 → 多轮改 → 升 1080p/4K；720p 约 $0.07/秒。
  • 已知不足（官方自述）：快速体育动作、剧烈剧本跳切、复杂物理仍在改进。
