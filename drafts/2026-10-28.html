世界模型Google DeepMind 发布 Genie 4：可听、可改、可实时「导演」的交互世界

结论：过去 24 小时对世界模型赛道最硬的一条。DeepMind 以研究预览放出 Genie 4：用户用键盘导航 / 转镜头，再用自然语言中途改天气、加角色、推事件；模型首次原生同步生成环境音、音乐与可对话角色。Gemini 家族（含 Omni 锚定外观、3.8 Flash 在环规划、实验里的 Gemini 4 Argon）负责推理与连贯，Genie 负责像素级世界。官方称连贯场景最长约 2 分钟（前代约 1 分钟）。产品形态仍未定；团队公开承认长时漂移、音频准度、世界内文字可读性未解。公开可用性：可信测试者 → 未来几周 Google AI Ultra / Project Genie + Gemini API / AI Studio 早期伙伴。

1. 发生了什么

美东 2026-10-27（北京约 10-27 深夜至 10-28 凌晨），DeepMind 发博客 Genie 4: A new generation of world simulation；Google Blog 同步短讯 Introducing Genie 4。TechCrunch 9:30 AM PDT 专稿；皮查伊与 DeepMind 官号同日推演。

2. 产品介绍

  • 控制方式：官方写明演示用标准键盘做导航与相机，再用文本提示实时改场景——和「WASD + 文字指令」路线同族，不是逐帧 6-DoF 相机轨迹接口。
  • 四大卖点（官方口径）：① 实时自然语言塑形世界；② 物理与人物动作更逼真；③ 原生音频（环境 / 音乐 / 互动对话）；④ 与 Gemini 闭环做多步事件与机器人仿真实验（例：Apptronik Apollo 下棋任务拆步）。
  • 时长：媒体与简报口径「连贯场景最长约 2 分钟」，约为 Genie 3 两倍；不等于两分钟内物体永不漂移。
  • 安全：生成音视频带 SynthID；先可信测试者再放宽。
  • 局限（官方自述）：长会话细节 / 物体持久性会漂；复杂物理、实时音频准度、世界内文字、空间精度、长期一致性仍是研究中。

边缘开源多模态Liquid AI 开源 LFM3：约 2B 档「文本+视觉+音频+决策」全家桶

结论：边缘 / 端侧赛道值得记的一条产品发布。Liquid AI 在 2026-10-27 放出 LFM3：六个约 2B 参数开源权重模型，共用 LFM3-1.7B-Base（预训练约 22T token），覆盖文本 Agent、视觉（含视频）、音频（18 语）、Omni、以及两个「决策」模型 d1 / d1-Omni。叙事是「专用小模型 + 单卡微调 + 端侧部署」，不是再堆一个通用聊天旗舰。VentureBeat / MarkTechPost / HF 博客均有稿；跑分与「打赢 Qwen3.5-9B 的 WebArena」等全是厂方自测，第三方独立 harness 成稿时仍少。

1. 发生了什么

Liquid 官方博客 Introducing LFM3（标注 OCT 27, 2026）；Hugging Face 同步 Build specialized multimodal models with LFM3 与 LFM3 Collection。许可走 LFM Open License：年收入约 ≤$1000 万可免费商用，之上需商业许可——落地前要核对。

2. 产品介绍

  • 六件套：LFM3-1.7B（文本，256K 上下文）· LFM3-VL-2B（图/视频）· LFM3-Audio-2B · LFM3-Omni-2B · d1-2B · d1-Omni-2B。
  • 架构卖点：三混合层（短卷积 + 滑动窗注意力 + 全局注意力）；厂方称相对 LFM2.5-2.6B 参数少约 35% 仍更强。
  • Agent 自测高光（务必标注厂方）：WebArena-Verified 38.42 vs Qwen3.5-9B 28.94；AutomationBench 公有评测 41.29 vs 15.10。MacPaw 引述：65 个 macOS 日常 agent 任务上 1.7B 成功率 64% vs Qwen3.5-2B 的 48%。
  • 怎么跑：HF 权重 + Playground + Liquid API；宣称 llama.cpp / MLX / vLLM / SGLang 等 day-0；AMD / Qualcomm / Ambarella / NVIDIA 等列为启动伙伴。
官方长文以图文与基准表为主；成稿未找到可下载的独立产品宣传长视频。所有「打赢更大模型」数字来自 Liquid 博客表格与合作方引言，读分时连评测设定一起看。
怎么看 打开 官方博客 滚完六模型表与 WebArena / AutomationBench 行；权重去 HF Collection。英文产品解读看 VentureBeat。
对我们意味着什么 与交互世界模型无直接对打，但「端侧多模态 Agent + 单卡专业化」会影响数据生产工具链选型：标注、质检、本地工具调用更可能跑小模型。若内部要便宜的浏览器/桌面自动化基线，可把 LFM3-1.7B 列入候选，先复现 WebArena / 自有任务再信厂方表。

结论：消费端「文档里的 Agent」又进一步。Apple Newsroom 2026-10-27 宣布 Creator Studio 大更新：Keynote / Pages / Numbers 内置基于 Apple 模型 + OpenAI 的智能助手（Beta），能理解当前文档上下文——做幻灯片、改文稿、算表与推荐图表；同时在 macOS 27+ 为三件套接入 MCP，让外部 AI Agent 直接读写与自动操作。十一月 App Store 推送给现有订阅用户；助手限 Apple Intelligence 设备、目前仅美式英语。同包还有 Logic Pro 助手、Pixelmator Generate Fill、Final Cut 内置 MotionVFX 等——本条只深挖「iWork + MCP」产品意义。

2. 产品介绍

  • Keynote：设计、动画、 refining 幻灯片。
  • Pages：起草、重组、润色文稿。
  • Numbers：计算、可视化、组织数据；一键预览图表类型；用世界知识建自定义表。
  • MCP：外部 Agent / 工具可在三件套内读内容、改内容、执行自动化（需 macOS 27+）。
  • 附带开放格式：Keynote 新增 .keyx（JSON bundle），方便外部工具与 AI Agent 读取。
  • 门槛：助手需 iOS 27 / iPadOS 27 / macOS 27 + Apple Intelligence 机型；目前 U.S. English only。
官方以新闻稿图文为主；成稿未见可下载的独立助手操作录屏。Beta 阶段能力边界以实机为准，勿把营销句当成稳定生产功能。
