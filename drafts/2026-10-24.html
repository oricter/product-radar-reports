世界模型腾讯混元开源 Hy-Nomas：文字多轮 + 相机轨迹的交互式视频世界模型

结论：过去 24 小时里对阿汤公司最相关的一条。腾讯把一套「按段生成、带世界记忆」的开源世界模型权重和代码推上了 Hugging Face / GitHub，并挂了可玩 demo；但没有发布任何官方分数，技术报告仍是 Coming Soon。适合先看 demo、对标我们的文字指令 + 相机控制路径，不要被「开源」两个字当成已验质量。

1. 发生了什么

北京时间 2026-10-23 傍晚前后，腾讯混元官方账号 @TencentHunyuan 发帖介绍 Hy-Nomas：开源、自由形式交互的视频世界模型。同一天，Hugging Face 仓库 tencent/Hy-Nomas 推上约 196GB 权重（Apache-2.0），代码仓 Tencent-Hunyuan/Hy-Nomas 与评测集 Hy-Nomas-Bench（280 题）上线，官网 demo：hy-nomas.hy.tencent.com。

独立拆解（OrcaRouter，10-23）指出：这是一次「权重先上、宣传很轻」的发布——模型卡写得很细，但没有 leaderboard 分数，技术报告链接仍 404。腾讯自己的 X 帖截至抓取时约 561 赞 / 2.5 万浏览 / 72 转，热度中等偏上，远低于同日 Kimi 官宣。

2. 产品介绍

它做什么：不是「一次文生视频出一条片子」，而是一段接一段地生成同一个世界。你可以：

  • 用自然语言多轮改剧情（加物体、换风格、改动作）；
  • 同时喂相机轨迹（外参矩阵），控制视角；
  • 用持久 KV cache 记住前面生成的内容，继续往后写。

官网写明规格口径：约 8B 参数、输出 720p、最长连续约 60 秒、蒸馏推理 8 步、回放帧率 24 FPS（注意：这是成片回放帧率，不是生成吞吐）。蒸馏配置默认要 8 卡并行；另有 单卡 RTX 4090 低显存路径（INT8 DiT + FP8 解码 + CPU offload）。还带电影向 LoRA 和双臂机器人 LoRA。

官方演示里能看到什么 打开 官网：多轮提示控熊猫爬柱、月面基地文字+相机交织、长镜头连续生成、回到旧场景的空间记忆样例，以及约 83 个风格/视角世界的预览墙。下面嵌入腾讯官方 X 演示前 45 秒精简版。

必要视频（页内可播）

谁发的：腾讯混元官方 X 发布附带演示（@TencentHunyuan，已裁成前 45 秒） 看完应搞懂：同一世界里用文字改剧情、用相机转视角时，画面是否还像「同一个地方」在延续。

和我们的关系 Hy-Nomas 的控制面是文字指令 + 相机轨迹（不是 WASD 实时键鼠），更接近「导演式交互世界」而不是「可玩即时游戏」。若我们打 WBench Full 的文字/视角类题，它是可下载的开源参照；但官方没交分数，不能直接拿来对标 WBench / WorldScore。

3. 导致什么影响（竞品对比）

对比谁差在哪（有证据）
EdenLive（已报道 10-19）EdenLive 强调代理几何→实时渲染、5090 上 720p>24FPS；Hy-Nomas 强调多轮文字+相机分段生成。一个偏实时可玩，一个偏可控长叙事。
AMD Micro-World 2（已报道 10-23）Micro-World 2 是键鼠实时交互，自报 WBench；Hy-Nomas 是文本/轨迹导演式，暂无公开榜分。
Matrix-Game 4.0（已报道 10-16）Matrix-Game 走引擎+AI 渲染、按键实时；Hy-Nomas 走 DiT 分段生成，默认算力门槛更高（8 卡或 4090 低显存折中）。
Kyutai CADRE（10-22 开源，窗口边缘）CADRE 聚焦「交互世界模型该怎么压视频 latent」，自报单 H100 <230ms 动作延迟；Hy-Nomas 是完整可交互生成产品栈，但缺延迟数字。
风险提示：Hy-Nomas-Bench 有题无分；「24 FPS」「60 秒」都是输出规格，不是实时性证明。引用质量前先自己跑 Bench 或等技术报告。

1. 发生了什么

NVIDIA Nemotron 实验室页标注 Published: October 23, 2026，发布 Nemotron 3.5 Bolt E4B 4GB。官方 X @NVIDIAAI 同步放出 Reachy Mini 机器人演示（Bolt 管对话，Cosmos 管视觉，都在 Jetson Orin Nano 8GB 本地跑）。Ollama、Unsloth 当天跟进可装。

热度很高：官方帖抓取时约 1319 赞 / 14.5 万浏览 / 151 转；Unsloth 转发帖约 1365 赞。

2. 产品介绍

  • 底座：Gemma 4 E4B + Nemotron 后训练；目标工作负载约 4GB 显存（Q4_K_M）；64K 上下文；35 语。
  • 能力开关：多轮工具调用、对话模式（更短、更适合语音）、可开关推理以换延迟。
  • 官方自报：相对自家前代 Nano 4B，对话 Agent 相关基准平均质量约 +40%；相对部分同级模型输出 token 最多可少约 80%（少废话）。
  • 硬件表：RTX 5070 / RTX Spark / Jetson Orin Nano 等都给了 TTFT 与 tokens/s（以官方表为准，属厂商自测）。

1. 发生了什么

北京时间 10-23 晚至 10-24 凌晨，月之暗面发布 Kimi K3.1 Pro。IT之家 10-24 07:08 中文快讯确认：1M 上下文、Highspeed 约 2–3× 输出速度、API 价目与 11-4 前放权重。@Kimi_Moonshot 官宣帖热度极高（抓取时约 2.1 万赞 / 176 万浏览）。

2. 产品介绍

  • 规模：约 2.8T 总参 / 104B 激活（MoE），多模态，1M 上下文。
  • 卖点场景：全项目级编程（含 Unity / Unreal / Godot）、参数化 3D（Blender/CAD，BenchCAD 工具分官方 92.7%）、金融工作流、Agent。
  • 新产品能力：kimi.ai / App 上线 3D Make（在线预览编辑 3D，可导出打印/视频）。
  • 安全叙事：主动削减网络攻击相关训练数据；自家 xdev-bench-hard 从「未削减版」90.5% 降到发布版 81%（仍远高于前代）。The Next Web 以「砍掉黑客技能」作标题。
  • 价格（IT之家转述 API）：输入缓存命中 ¥1.3/M、未命中 ¥13/M、输出 ¥68/M；Highspeed 输出更快、价格约 2×。美元价在海外渠道常见口径约 $2/$10（Pro）。
怎么亲自看 打开 官方博客 看编程 / 3D / 金融案例；再打开 Artificial Analysis 看第三方智力指数与 Agent 分项；产品侧直接在 kimi.ai 或 Kimi Code 选 kimi-k3.1-pro。
