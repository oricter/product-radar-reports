2. 产品介绍

我把官方 91 秒中文宣传片和 66 秒城堡对比视频都逐帧看过。它是三层结构：

  • 游戏引擎（管「发生了什么」）：负责世界状态、规则、碰撞、NPC 行为，只渲染一个很粗的低模画面（彩色方块小人、纯色墙面）。
  • Coding Agent（管「改规则」）：你用自然语言说「我要无敌模式」，它改游戏代码里的规则，并把当前状态写成给视频模型的提示词。
  • 视频模型（管「画面」）：基于阿里 Wan2.2 5B 改的因果自回归模型，每次出 4 帧、只去噪 1–2 步，把低模画面 + 参考帧 + 提示词实时渲染成写实画面。另有「空间记忆」：按相机位置找回以前看过的画面，避免回头时场景变样。

3. 导致什么影响

对行业：「世界模型做游戏」出现了一条和 Genie 3 完全不同的路线——不让模型去记住和推理世界，而是让游戏引擎管状态、模型只当「AI 渲染器」。好处是规则可控、能做射击和赛车这种要求严格的玩法、能在单卡上跑；坏处是失去了「一句话生成新世界」的能力。NVIDIA 的 StreamRender-H3 也是这条路线，说明这已经不是一家的想法。

对开源生态：权重 + 数据管线 + 场景资产都放出来，任何团队都能在同样的硬件上复现和比较；GitHub 上已经有人提「接入 Roblox」的需求（Issue #87）。

竞品对比

谁做法和硬件差在哪（有证据）
Matrix-Game 4.0（昆仑万维）引擎 + AI 渲染，1 张 RTX 5090480p / 60 帧，延迟 112 毫秒（自测）；完整开源。

AgentGarten / Code World Model大模型写代码生成世界同一张表里延迟约 878 毫秒（1×H100）和约 10.2 秒（H200），不是实时游玩。
Genie 3（Google）纯模型生成世界，云端720p / 24 帧，能一句话生成新世界，但不开源、要订阅；规则不可编程。
Matrix-Game 3.5（上一代）纯模型，H100720p / 20 帧。4.0 用更低分辨率换来了 3 倍帧率和消费级显卡。
和我们的关系：4 个值得问算法同学的问题
  • 数据：他们用 1,712 小时 UE5「低模 ↔ 写实」配对数据训渲染器。我们的数据产线能不能顺手产出这种配对数据（同一段轨迹同时导出白模和成品）？这可能是一个新的数据品类。
  • 控制方式：它的输入是 WASD + 射击 + 自然语言改规则，和我们的 WASD + IJKL + 文字指令很接近，可以直接拿来当对照组。
  • 延迟：112 毫秒 / 单卡 5090 会成为大家引用的标杆。我们自己的按键到出画延迟是多少？
  • 路线选择：「引擎管状态」解决了一致性和规则问题，但换来「一个游戏一个模型」。我们走的是哪条，对外怎么讲差异？

2. 产品介绍

  • 长度：原生 3–30 秒一条，不用拼接。
  • 参考素材（Omni Reference）：最多 15 个（图片最多 10 张、视频最多 5 段、主体最多 7 个），参考视频可以是白模或深度图——也就是可以先用 3D 软件摆好镜头，再让模型出成片。

  • 声音：立体声，口型更准，支持多语言和方言。
  • 还没上的（官方写「即将推出」）：10-bit HDR 4K / 1080p 输出、一次续写到 2 分钟、API。

3. 导致什么影响

对行业：头部视频模型的竞争点已经从「画面好不好看」转到「导演能控制多少」：长度、参考素材数量、关键帧、白模参考。可灵 4.0 在这几项上追平了 Seedance 2.5，但参考素材数量仍然少于 Seedance。

对 Agent 生态：MCP / 命令行入口让可灵可以被 Claude、Cursor 之类的 Agent 直接调用，几位海外用户认为这是被低估的功能。

和我们的关系
  • 白模参考 = 我们产线的上游素材也能用：可灵 4.0 和 Seedance 2.5 都接受白模 / 深度图视频当参考。如果我们要「同一段白模轨迹 → 多种写实风格」的数据，可以拿它们当外部渲染器小规模试，比较结构跟随程度。
  • 注意它们不是实时的：30 秒视频要离线生成、按条付费，和我们的实时交互世界模型不是同一种产品，不要放在同一张对比表里讲。

2. 产品介绍

  • 规模：8160 亿总参数、每次激活 420 亿（混合专家，256 个专家选 8 个）；上下文 100 万 tokens。
  • 输入输出：能读文字、图片、视频、音频，只输出文字。主打写代码和 Agent 长任务。
  • Mac 上的官方演示（Meta 博客）：在两台 Mac Studio 上完全本地运行 Muse Code，给开源 iOS 应用 Ice Cubes（一个 Mastodon 客户端）修 bug、加功能、完整编译；还能端到端操作 DaVinci Resolve 剪辑软件，由模型逐帧看素材。
  • 硬件：BF16 权重约 1.65TB；NVFP4 量化后约 537GB，需要 700GB 以上显存/内存。
  • 许可证：Muse Model License，有商用限制——要标「Built with Muse Spark Open」；据 X 用户 @Ldataengineer 解读，收入超过 2000 万美元的 AI 服务商需要另谈授权。
  • 价格（第三方）：Artificial Analysis 按 Together / Fireworks / Baseten 当前价（每百万 tokens 输入 1.25 / 输出 4.25 美元）算，每个评测任务 0.84 美元，不到 GLM-5.3 的一半，约是 DeepSeek V4.1 Flash 的 3 倍（AA 原帖）。
