2. 产品介绍

我看了官方博客、VentureBeat 长文和 Google Cloud 官方演示视频后的理解：

  • 入口：一个提示框 / 一个 API；可在 Workspace、Microsoft 365、Slack、桌面、手机、命令行里用。
  • 同事模式：可为 Agent 开独立 Workspace 账号（邮箱、日历、Drive、通讯录），别人可以 @ 它；操作记在 Agent 身份的审计日志上。
  • 四种记忆：会话 / 语义 / 程序（含自写 Skills）/ 情景。
  • 多模型：默认智能路由；已支持 Gemini 系 + Anthropic Claude，管理员可限制可用模型。
  • 状态：企业私有预览；宣称纳入现有 Gemini Enterprise / Workspace 商务套餐不加价，但席位与长跑任务计量细节未钉死。

2. 产品介绍

我打开项目页并通读论文 HTML 后看到的结构：

  • Stage 1：事件级视频续训（详细 caption：哪只臂、哪个物体、完整操作过程）。
  • Stage 2：固定时长 chunk 后训练 + 一致性蒸馏 → 单步视觉规划（约 0.12s 预测约 8s 机器人画面）。
  • Stage 3：0.9B Action DiT（MoT）学隐式逆动力学；前期冻视频骨干 + LoRA，减轻动作训练伤泛化。
  • 上层：可接 VLM 做子任务规划；论文称选定长程任务上成功率 27.6%→57.6%。

项目页提供大量 open-world 人手 / 机械臂预测对比动图；本期未另嵌第三方解说视频（海外高播介绍尚少），建议直接看项目页动图 + 论文图 5–8。

3. 导致什么影响

对做白模世界 / 世界动作数据的团队：VPP2 把「预测泛化」和「行动泛化」拆开训练的工程叙事很清晰——详细事件 caption、坐标系统一、T 形多视角，都是数据产线可直接对照的清单。
