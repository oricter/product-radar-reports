2. 产品介绍

我逐帧看了官方 105 秒发布视频和 32 秒角色演示，读了三篇研究页。它的做法拆开是这样的：

  • 世界怎么存：整个世界是一堆持久存在的 3D「原子」（官方叫 Physics-Native Tokens）。每个原子有明确的 xyz 坐标，加上学出来的「外观」和「动力学」向量。生成一次就固定下来，换角度看不用重新跑模型。
  • 怎么变成画面：解码器把原子转成 3D 高斯泼溅，在用户浏览器本地渲染；也可以解码成图片。
  • 场景：从文字、单张图或全景图生成，最多可以吃 64 张不同角度的输入图当空间参考。「Expand」按钮会补全看过去发糊或发黑的区域。官方说 B200 上约 1 秒一个场景。
  • 角色：一张照片或一句话生成全身 3D 角色，动作能力直接长在角色里，不用单独绑骨和蒙皮；手指能独立动；被遮挡、截断的照片也会自动补全身体。
  • 动作：从文字或任意视频（包括手机随手拍）提取全身动作，可以套到 JST-2 角色上，也可以导出 GLB/FBX 给 Unity、Blender。
  • 价格：网页版角色 10 点一个，动作 1 点/秒；开发者 API 上文字生成场景 0.06 美元一次，其他场景操作 0.01 美元一次（Build Fast with AI 引用的官方价目）。

3. 导致什么影响

对行业：世界模型现在分成两派。像素派（Genie 3、Odyssey-3、我们）直接生成下一帧画面，动态和真实感强，但空间一致性靠模型自己记；3D 派（World Labs Marble、JST-2）先生成 3D 结构再渲染，空间稳定、能导出复用，但动态和互动弱。JST-2 是 3D 派里第一个把「场景 + 角色 + 动作 + 文字指令」放进同一个模型、并且免费开放的。官方发布帖第一句就是「多数世界模型在像素/视频空间里学」，这是直接拿像素派做靶子。

对游戏和 3D 工具：它同时进了三块地盘：3D 资产（Meshy、Tripo）、动作生成（Cartwheel、DeepMotion）、场景生成（Marble）。官方在 X 上回复用户说，目标用途是「游戏、原型和互动体验」。

和我们的关系：3 个值得问算法同学的问题
  • 路线叙事：JST-2 公开说「像素空间世界模型」不够好。外部会越来越多地问：你们的模型转一圈回来，场景还一样吗？我们需要一个有数据的回答，比如回访一致性的指标。
  • 数据产线：1 秒一个 3D 场景、不到 1 美分、能导出泼溅文件、场景里能用 WASD 走。能不能拿它批量生成场景，再按我们的 WASD + IJKL 轨迹渲染成训练或评测数据？要先看清服务条款，确认是否允许把输出用于训练。
  • 评测：3D 场景天然有「真值」，同一个位置从哪个方向看都一样。可以用它给我们自己的模型做空间一致性测试题。

2. 产品介绍

我看了官方 2 分钟发布视频，读了官方研究页和机器之心全文。拆开是这样的：

  • 怎么用：开发者注册拿到 API key，几行 Python：发三路相机画面（头部 1 路 + 每只手腕 1 路）、机器人当前状态和一句自然语言任务，返回接下来 1.6 秒的动作。
  • 为什么能换机器人：模型同时学「预测视频」和「预测动作」。在头部相机看来，任何机器人都只是画面里移动的形状，所以只要它能想象出新机器人完成任务的样子，就能反推动作。输出的是夹爪最终位置和开合，再交给每台机器人自己的逆运动学求解器（IK）换算成关节指令。
  • 价格：Dream-1 每小时 3 美元，Dream-1-flash 每小时 2 美元（官方）。
  • 微调服务（FaaS）：遇到不支持的硬件，提交少量演示数据，几小时拿到定制模型。官方说一条 5 分钟的轨迹，就让 12 台 Beta 机器人里 10 台的指令遵循变好了。
  • Robot Playground：不用买机器人，浏览器里给旧金山办公室的真机下指令，实时看反应，不剪辑。
  • 官方写明的局限：效果取决于每台机器人 IK 的质量；只管夹爪到哪，不管手臂怎么过去，靠近障碍物或关节极限时可能出问题；和训练里差别很大的机器人，可能算出做不到的动作。下一步支持轮式移动机器人和灵巧手。

3. 导致什么影响

对具身行业：以前想让机器人用上基础模型，要么自己下载 GR00T、π 这类开源模型，租 GPU 训练再部署（Forbes 引用创始人的话：「光解决一个问题就要三到六个月」），要么和厂商深度合作。Dream Labs 把它做成了「注册、拿 key、接机器人、按小时付费」，和大模型 API 的普及路径一样。

对世界模型：「世界动作模型」半年内成了具身最热的路线之一（机器之心）。这说明世界模型的价值不只在「生成可玩的世界」，也在「预测之后能不能行动」。Odyssey-3 也在讲机器人方向，现在有人先把它做成了收费产品。
